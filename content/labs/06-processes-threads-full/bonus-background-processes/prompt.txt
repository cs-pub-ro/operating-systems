Bonus (a): the shell running a process in the background.

If a command's line ends with `&`, the shell spawns the process but does NOT
wait for it, so the user can type the next command at once.  The full
directory explains how to reap zombies (WNOHANG loop, or SIGCHLD); the TODOs
hint at both.

Builds on 02-shell-builtins: run_command() gains a `background` flag, main()
detects a trailing `&`, and reap_background() collects finished children with
`waitpid(-1, WNOHANG)` before each prompt.  No `;`/`&&`/`||` here -- those are
the next bonus, which builds on this one.
