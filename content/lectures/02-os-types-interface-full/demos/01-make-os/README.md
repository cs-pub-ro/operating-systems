# Demo: Building an Operating System

One demo for part 01, on what actually goes into "an operating system".

| Demo | What it shows |
| --- | --- |
| [`unikraft/`](unikraft) | Even the smallest specialised OS, built to run one `Hello, World!`, is hundreds of kilobytes and hundreds of symbols. |

The point is the same as the pitch, one level down.
The pitch showed how much the kernel does for an application; this shows how much *is* the kernel, even when it is stripped to the single application it was built for.
