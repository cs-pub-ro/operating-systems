# Demo: Why Care About Memory?

Four short demos, one per reason: memory runs out, memory you do not see speeds things up, where data sits decides speed, and memory you forget to free is gone.

| Demo | Shows |
| --- | --- |
| [`memory-use/`](memory-use) | The browser at the top of `ps`. |
| [`buffer-cache/`](buffer-cache) | 31 GB of `buff/cache` on a 59 GB machine. |
| [`cache-memory/`](cache-memory) | Row-major 0.05 s, column-major 0.46 s. |
| [`memory-leak/`](memory-leak) | 4,000 blocks definitely lost. |
