We are preparing contents for a class on Operating Systems, part of a 4-years bachelor study program in a technical university.
The class is part of the 2nd year, 1s semester.

Thare will be 12 practice sessions.
Each practice session has a directory names `session-NN-<session-name>`.
Practice session consists of:
- demo exercises: one demo (out of potentially many) will be solved together with the teaching assistant at the start of the session
- exercises: to be solved individually or in teams, in a given order, as indexed by a prefix number in the exercise name
- bonus exercises: optional exercises to be solved by those who move fast and get past the common exercises, to be solved in any order

For each session, add a top-level `README.md` file at the root of any `session-NN-<session-name>` directory.
The `README.md` should present:

- the learning objectives
- the order of the tasks and which are core versus optional
- the estimated time budget per task
- the prerequisites and required tools
